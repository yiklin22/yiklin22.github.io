redactgate. Personal data out before the prompt.

Pasting a customer email into ChatGPT or Claude sends personal data off the machine. redactgate swaps names, card numbers, IBANs and addresses for placeholders on your own machine, then puts the real values back into the model’s answer.

84.1%

of labelled personal values masked on 2,891 English test documents (6,900 of 8,205). Microsoft Presidio’s default setup: 52.7%.

Limit: 24.0% of documents still leak at least one value, so a person reads the redacted text before it is sent.

Names out before the prompt, back in after

Situation

Loan forms, SWIFT messages and customer emails carry names, cards and IBANs. Pasting them into a hosted model sends personal data off the machine, which EU businesses under GDPR have to answer for.

Obstacle

The model still needs to know who did what, so values cannot simply be deleted. The test data is synthetic and its labels miss some real personal data, so the measured share of masks that hit real personal data, 65.1%, is only a floor; a hand check of 100 masks put it near 88%.

Action

Card numbers and IBANs found by pattern and confirmed by their check digits; names and places found by a multilingual name-finding (NER) model on CPU; then one numbered tag per value. Rules were tuned on dev; the English test split has been run five times, once per version, with no tuning after a run.

Result

84.1% of values masked on the English test split, against 52.7% for Presidio’s defaults, and 71.5% or more in five other languages. This compares defaults: Presidio with custom recognisers would close much of the gap.

Constraints: a CPU, no API key, a public synthetic dataset (Gretel’s synthetic_pii_finance_multilingual), labels that miss some real personal data.

Placeholders, not deletions

The decision

Each value becomes a numbered tag such as PERSON_1 in brackets, and the same value always gets the same one, so the model can still write to the customer by name. The mapping never leaves the machine, and restore swaps the real values back, even where the model dropped the brackets.

What was dropped

A leak analysis of the dev splits ranked the causes of every missed value. The second largest, names the NER model tags as companies, was tried and dropped: masking them lowered the measured precision on every dev split. Address patterns, the largest cause, were kept.

Run redactgate yourself

Python, and about 1 GB for the NER model, downloaded on the first run. The demo calls no API: its model answer is written by hand. The evaluation downloads Gretel’s test set from Hugging Face.

Where the figure comes from

docs/results-en-test-multi-model.md, written by scripts/evaluate.py --split test, with the per-type table and the Presidio run beside it.

redactgate / terminal
$ uv venv && uv pip install -r requirements.txt
$ source .venv/bin/activate
$ python scripts/demo.py  # first run downloads the NER model (about 1 GB)
$ uvicorn redactgate.app:app --port 8840  # page at http://localhost:8840
$ pytest -q -m "not model"  # fast tests, no model download
$ python scripts/evaluate.py --split dev  # first 500 train documents
$ python scripts/evaluate.py --split test  # run once
