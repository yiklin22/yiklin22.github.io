Knowledge system. AI proposes, a person approves.

Chat-with-your-documents tools answer fluently and invent citations. Here an agent proposes notes from saved sources, code checks every quote word for word, and nothing becomes knowledge until a person approves it.

Notes a person can audit

Situation

Teams read vendor docs, chats, PDFs and videos, then cannot answer “where did we learn that, and can we trust it?” Chat tools answer fluently, but nobody can audit what they cite.

Obstacle

A hostile web page or PDF can carry orders for the agent that reads it. A prompt that says “never fabricate quotes” is a request, not a guarantee.

Action

The digest agent runs with an allow-list: it writes only inside proposals/, has no web access and cannot approve. A validator re-checks every quote against its source, and approval happens in the browser.

Result

18 of 18 attacks that need a forbidden action stopped by the allow-list or the validator. The validator refuses any quote it cannot find word for word, and all 160 approved quotes pass.

Constraints: one user, local only, live red-team and judge runs that cost $0.79 and $0.14, 96 tests in CI.

Evidence checked by code, not by the prompt

The decision

A validator re-checks every quote verbatim against its raw file, requires a locator with each one, and the approval gate refuses a batch with errors. It checks that the quote exists; whether the quote supports the claim is for the person who approves.

What was dropped

The first quote check had a hole the red team found: a source page could name a file the agent had just written in proposals/ as its raw text, so an invented quote passed as verbatim. Raw paths must now resolve inside raw/, and a test replays the attack.

Run Knowledge system yourself

Python; Docker if you prefer a container. The demo runs on a small sample vault in a throwaway copy, so nothing you do in it is kept. The structural red team is free and runs in CI.

Where the figure comes from

docs/redteam-results.md, written by python -m tools.kb.redteam, with every attack, its category and what stopped it.
