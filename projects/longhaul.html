longhaul. What a long agent run costs.

A long agent run ends up holding more text than the model can read at once, so teams choose what to drop: keep everything, cut old turns, delete old tool outputs, or summarise. longhaul measures whether the facts the agent needs are still in its prompt, and prices the bill with cache reads and writes counted apart.

$1.84

modelled per 120-turn shift for full history with caching, against $28.56 without, over 10 modelled shifts at Opus 5.5 prices.

Limit: costs are modelled, and memory is scored by a stand-in model that reads perfectly, so a real model can only do worse. No live-model run exists yet.

A day-long agent, priced the way it is billed

Situation

A support agent that runs all shift outgrows its context window. Most comparisons price every input token at full rate, which is not what a cached agent loop pays.

Obstacle

The provider bills text it saw recently at a lower, cached rate, and the cache expires after 5 minutes or 1 hour. With no API key for a live run, the bill had to come from replaying every call through a model of that cache.

Action

Built on Inspect AI, testing Inspect’s own compaction strategies rather than copies. A seeded 120-turn shift states facts, changes some, and asks for them many turns later.

Result

Caching outweighs the choice of strategy: full history costs about 15 times more uncached. Clearing old tool results kept 94% of the evidence at $1.14 a shift; trimming kept 48% at $1.35.

Constraints: no API key, a mock reader, Anthropic’s published prices as of 2026-11-03, estimated token counts, 39 offline tests and a regression gate in CI.

Inspect’s own strategies, priced with the cache

The decision

Test what Inspect users actually run (CompactionTrim, CompactionEdit, CompactionSummary, CompactionNative) and price every call with cache reads and writes apart. That is what shows the pause between turns changing the answer: if the agent waits more than five minutes, a plain cache expires and the whole prompt is paid for again.

What was dropped

Giving the trimming agent Inspect’s memory tool, to save notes before each trim, raised its cost from $1.35 to $1.82 a shift, about the price of sending full history. Whether the notes win back what trimming drops needs a live run, so the mock’s score for it is not reported.

              a kind of fact for

Run longhaul yourself

Python; the offline run needs no API key. A live run needs ANTHROPIC_API_KEY, and longhaul.plan prices a sweep’s prompts before any money is spent.

Where the figure comes from

docs/results/offline.md, written by python -m longhaul.sim; the regression gate fails CI if a strategy keeps less evidence or costs more than the committed baseline.
