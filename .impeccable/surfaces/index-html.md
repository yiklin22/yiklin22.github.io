# index.html

Scope: the whole one-page portfolio. Mode: Experience. Audience: hiring managers on a laptop, deciding within a minute
whether to read one project. Action: open the GitHub profile. Constraints: static, no build step; the pass mark demo
stays interactive with its scores named as simulated; display name "Eagle", GitHub only.

## Direction contract

THESIS: the work is shown as the review tools the projects really have, with one figure per project in the text. It
refuses the report layout of big figures with sample-size tickets that the page had before.

OWN-WORLD: deep forest green page, pale lime as the single "passed" colour, light sage panels behind live UI, one
white band. Sora for display, Figtree for text, Martian Mono for receipt lines, scores and code. Sharp 4 to 8px
corners. Everything sits on the taste-skill kit's grid and section rhythm.

STORY: this engineer builds AI systems and tests how often they are wrong; here is the gate you can drag; here are
three systems, each with one result and one limit; get in touch through GitHub.

FIRST VIEWPORT: the triptych hero. The h1 "AI engineer who tests the work" on three lines at the left with the lead
and its one fact (17.2% to 2.7% on 200 held-out receipts); a collage of three sets in the middle (receipt and
approved total, cost of a long run, a note with its quote check); the lime "See my GitHub" button at the right line.

FORM: taste-skill deal (hero triptych, nav-centre, close-type, footer-columns, dark-band, tonal buttons, palette
forest-pale-lime, pairing sora). seed: none (pinned) "use impeccable and taste skill from github ... make it as
pretty as possible don't need to over generate numbers".

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
