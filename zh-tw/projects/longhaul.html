longhaul。一次長時間代理執行要花多少錢。

長時間的代理執行，最後累積的文字會超過模型一次能讀的量，因此團隊必須選擇丟掉什麼：全部保留、刪掉舊回合、刪除舊的工具輸出，或做摘要。longhaul 量測代理需要的事實是否仍留在提示詞中，並在快取讀取與寫入分開計算的情況下估算帳單。

$1.84

是有快取的完整歷史在每個 120 輪班次的模擬成本，無快取則為 $28.56；以 Opus 5.5 價格模擬 10 個班次所得。

限制：成本是建模估算的，記憶則由一個讀取完美的替身模型評分，所以真實模型只會更差。目前還沒有用真實模型執行過。

開啟儲存庫

一個 120 輪的班次，完整歷史

有快取$1.84
無快取$28.56

一個跑整天的代理，照實際計費方式算成本

情境

一個整個班次都在執行的客服代理，會撐爆它的上下文視窗。多數比較都以全價計算每個輸入 token，但這不是有快取的代理迴圈實際付的錢。

阻礙

服務商對最近看過的文字以較低的快取費率計費，而快取會在 5 分鐘或 1 小時後過期。由於沒有 API 金鑰可做真實執行，帳單只能靠把每次呼叫重播進這套快取的模型來算出。

行動

建於 Inspect AI 之上，測試的是 Inspect 自己的壓縮策略，而不是複製品。一個以固定種子產生的 120 輪班次會陳述事實、修改其中一些，並在許多回合之後詢問它們。

結果

快取比選擇哪種策略更重要：不用快取時，完整歷史的成本約高出 15 倍。清除舊的工具結果，以每班次 $1.14 保留了 94% 的證據；截短歷史以 $1.35 只保留 48%。

條件限制：沒有 API 金鑰、使用模擬讀取器、採用 Anthropic 截至 2026-11-03 公布的價格、估算的 token 數、39 項離線測試，以及 CI 中的回歸關卡。

Inspect 自己的策略，連同快取一起計價

決策

測試 Inspect 使用者實際在跑的策略（CompactionTrim、CompactionEdit、CompactionSummary、CompactionNative），並為每次呼叫計價，快取讀取與寫入分開計算。正是這樣，才看得出回合間的間隔會改變答案：只要代理等待超過五分鐘，一般快取就會過期，整份提示詞得重新付費。

捨棄了什麼

讓截短歷史的代理使用 Inspect 的記憶工具，在每次截短前先存筆記，使它的成本從每班次 $1.35 升到 $1.82，大約等於送出完整歷史的價格。這些筆記能否補回截短所丟掉的內容，需要真實執行才知道，因此不回報模擬讀取器給它的分數。

longhaul / 探針

自己執行 longhaul

需要 Python；離線執行不需要 API 金鑰。真實執行需要 ANTHROPIC_API_KEY，而 longhaul.plan 會在花任何錢之前，先為一次掃描的提示詞估價。

數字從哪裡來

docs/results/offline.md，由 python -m longhaul.sim 產生；若某個策略保留的證據變少或成本高於已提交的基準，回歸關卡就會讓 CI 失敗。

閱讀 README 與完整結果

longhaul / 終端機
$ uv venv && uv pip install -e .
$ python -m unittest discover -s tests -t .  # 39 tests, no API key
$ python -m longhaul.sim  # the offline table, about a minute
$ python -m longhaul.sweep  # pause and threshold sweeps, about three minutes
$ python -m longhaul.gate  # regression gate against baselines/offline.json
$ python -m longhaul.plan --turns 60 --seeds 3
